# 公众号文章大纲

## 标题（备选）

1. **"当制冷工程师学会用 AI：我用 AI 重构了技术规格书的工作流"**

---

## 第一部分：痛点场景（约 15%）

**开篇故事**

> "周五下午 3 点，我刚把第 287 页规格书的流程图对齐，领导说：'这部分要加一页测试方案，往后挪挪...'"

**三个痛点**

1. **格式黑洞** — 300 页规格书，调格式比写内容花时间
2. **AI 失效** — AI 能写内容，但直接输出 PPT 格式灾难
3. **逻辑迷失** — 忙着对齐、调字号，忘了自己到底要说什么

---

## 第二部分：转折点（约 20%）

**觉醒时刻**

> "我意识到：我在做一个'格式工'，不是工程师"

**新思路：中间层**

- AI 擅长：生成 Markdown 结构化内容
- 工具擅长：Markdown → 规格书 PPT 格式
- 我擅长：业务逻辑、技术方案

**工作流重构**

```
旧流程：想逻辑 → 写内容 → 调格式（3天）
新流程：想逻辑 → AI生成MD → 一键转PPT（5分钟）
```

---

## 第三部分：方案效果（约 30%）

**技术选型：为什么是这些格式？**

**Markdown：AI 时代的通用语言**
- 结构化、纯文本、AI 最擅长处理的格式
- 与生俱来的"内容与格式分离"特性
- 技术文档的事实标准

**Mermaid：用代码画图**
- 流程图、时序图、架构图，代码即图形
- AI 能理解逻辑关系并生成代码
- 版本控制友好，修改不留痕迹

**LaTeX：数学公式的标准**
- 技术规格书的必备能力
- 从计算公式到热力学方程
- 行业通用，专业表达

**工具能力展示（配图）**

1. **一键转换**
   ```bash
   node md_to_ppt.js -i spec.md -o spec.pptx
   ```
   一行命令，Markdown → 规格书 PPT

2. **7 种图表类型** — 流程图、时序图、类图、状态图、甘特图、饼图、思维导图
3. **数学公式** — LaTeX 公式自动渲染为 SVG
4. **表格排版** — 支持内联格式（加粗、斜体、代码）
5. **代码块高亮** — 灰底框，专业展示
6. **引述框** — 蓝底 + 💡 图标，重点突出
7. **智能分页** — 内容过多自动新建页面
8. **竖版/横版** — 适配不同输出需求

**规格书必备元素全覆盖**
- 参数对比表 ✓
- 系统流程图 ✓
- 计算公式 ✓
- 测试方法代码 ✓

## 第四部分：效果对比（约 20%）

**Before/After**

| 维度     | 旧流程             | 新流程               |
| -------- | ------------------ | -------------------- |
| 耗时     | 3天                | 5分钟                |
| 聚焦     | 格式               | 业务逻辑             |
| 修改成本 | 高（牵一发动全身） | 低（改 MD 重新生成） |
| 格式统一 | 靠手动             | 模板自动             |

**真实案例**

- 某项目 200+ 页规格书
- 原计划 2 天排版
- 实际 5 分钟搞定 + 1 小时内容优化
